# @deepseek-ai/dsh-client-ui-coding-timer

[English](README.md) | 中文

Web 编码时长追踪插件：帮助把握每日编码量的个人健康面板。浏览器半边在侧边栏声明的 `sidebar.timer` 位置（“新会话”按钮与工作区浏览器之间）注册一行控件：一个“开始编码 / 停止编码”开关，以 `h:mm:ss` 跳字计时当前时长，旁边一个信息按钮打开时长统计日历。侧边栏折叠成窄栏时，该行变为单个图标开关，提示气泡中显示同样的计时读数，并以圆点标记计时状态。

没有会话在计时时，**专注门禁**会遮住整个界面：一个全框遮罩（布局的 `shell.overlay` 位置中唯一有意遮挡的注册项），只显示今天已编码的总时长和一个“开始编码”按钮——打开 GUI 变成一个刻意的动作，而不是继续消磨的邀请。开始计时即揭开遮罩（下层应用从未卸载，状态不丢）；停止计时遮罩回归。计时中的会话也会自我保护：没有任何输入活动（点按、打字、指针移动、滚动）满 `idleMinutes` 分钟后，计时器自行停止，并把会话结束时间记为最后一次活动而不是触发时刻——忘记停止的计时绝不会把闲置尾巴计入时长，回归的遮罩就是重新进入的提示。两个偏好都存于 Host 用户设置文档的 `coding-timer` 命名空间（`gate` 与 `idleMinutes` 字段，模式默认 `true` 与 10 分钟），指向同一部署的每个回环浏览器都遵守同一选择。从遮罩上的“保持界面常显”链接或统计日历弹窗底部的设置行关闭门禁；所有入口写入同样的字段。

日历是周一开头的月度网格：每个日期格显示当天总时长，每行末尾显示该周总计，顶部汇总条显示今天与本周。跨午夜的会话按天拆分，深夜编码计入实际发生的那一天；正在进行的会话实时计入今天与本周。月份导航切换网格且不丢失历史。

状态是带运行时引擎 `persist` 通道的 `defineStore` 声明，进行中的计时与已完成会话历史经 localStorage 在页面刷新和插件 HMR 后保留。开始/停止在安全方向上幂等——计时中再开始、停止中再停止都是空操作——早于开始时间的停止记录零时长会话而非负数。store 是历史的唯一副本：计时器从不进入会话日志，也没有任何模型可见的工具读取它。偏好对是独立的 Host 侧状态（节点半边在组合了设置提供方时注册命名空间模式）；首次设置读取进行中时门禁不渲染，已关闭的门禁绝不会闪出遮罩。

文案双语：插件在 `dsh-client-locale` 的 `coding-timer` 命名空间注册 zh/en 词典，切换语言会重渲染已挂载的行与日历。

## Model Experience

无。该追踪器是纯浏览器端的健康面板：不挂载工具、不贡献提示词段落、不记录会话事件，其持有的任何内容都不会进入模型请求。

#### KV Cache 影响

无；该包既不组装也不发送提供方请求，零模型 token 开销源于它没有模型可见面。

## 已知限制与延后工作

- **历史按浏览器隔离**——localStorage 持久化把统计绑定到一台机器的一个浏览器档案，没有跨设备汇总。
- **历史无上限增长**——已完成会话持续累积（每条约 50 字节，多年使用也在存储预算内）。
- **窄栏隐藏日历**——折叠时只有开关可达；打开侧边栏才能使用信息按钮。
- **闲置监视只看输入**——读代码或思考而不碰设备满 `idleMinutes` 分钟会在会话进行中停止计时；不合适就在统计弹窗里调大该值。
- **偏好仅限回环**——设置 RPC 仅回环可达，远程（局域网）浏览器的 scope 运行在内存模式：门禁保持默认开启，写入入口会隐藏而不是吞掉一次无效写入。
