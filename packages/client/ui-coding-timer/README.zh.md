# @deepseek-ai/dsh-client-ui-coding-timer

[English](README.md) | 中文

Web 编码时长追踪插件：测量“在场”而非“声明”的个人健康面板。每一次交互——点按、点击、指针移动、打字、滚动——都是共享编码活动日志上的一枚打点(`dsh-coding-activity`,网关在 `coding.read`/`coding.write` 背后的同一 Host 文档 `$DSH_HOME/coding-activity.json`);编码时长就是相邻间隔小于两分钟的一串打点的总长:孤立的打点不计时,但充当下一枚打点的锚点,桌面与手机上的突发落进同一份历史。浏览器半边在侧边栏声明的 `sidebar.timer` 位置(“新会话”按钮与工作区浏览器之间)注册一行控件:进行中/休息中指示与当前区间的 `h:mm:ss` 跳字计时、今天的总时长,以及打开时长统计日历的信息按钮。侧边栏折叠成窄栏时,该行变为单个图标按钮:提示气泡显示同样的读数,圆点标记在场状态,点击同样打开日历弹窗——窄栏也能进日历。

离开时,**空闲遮罩**回来:本页签没有输入满 `idleMinutes` 分钟后,全框遮罩(布局的 `shell.overlay` 位置中唯一有意遮挡的注册项)把整个界面藏起,只显示今天已编码的总时长与返回提示——回到 GUI 变成一个刻意的动作,而不是继续消磨的邀请。任何交互都会揭开它:打点监听挂在 window 捕获阶段,在遮罩上动一下鼠标本身就重新打点,下层的应用(从未卸载)随即回来;再度空闲遮罩再度出现。两个偏好都存于 Host 用户设置文档的 `coding-timer` 命名空间(`gate` 与 `idleMinutes` 字段,模式默认 `true` 与 2 分钟),指向同一部署的每个回环浏览器都遵守同一选择;从遮罩上的“保持界面常显”链接或统计弹窗底部的设置行关闭遮罩,所有入口写入同样的字段。

日历是周一开头的月度网格:每个日期格显示当天总时长,每行末尾显示该周总计,顶部汇总条显示今天与本周。跨午夜的区间按天拆分,深夜编码计入实际发生的那一天;正在进行的区间实时计入今天与本周。所有读数——行计时、日历格、遮罩总计——都来自同一个投影(`displaySpans`:服务器规范合并的区间加上本地待发的打点,活尾延伸到渲染时刻),任何两处读数不会不一致。

本页签的一切线上动作都由 apply 中的一个控制器负责:窗口输入至多每秒打一枚点,批次在尾随 3 秒后写入 `coding.write`(失败 15 秒后重试,页面隐藏时尽力一写),转发的 `coding-activity/updated` 事件触发刷新,快照(视图加待发打点)供响应式 hook 消费。退役的 localStorage 历史一次性迁移到共享日志(迁移瞬间仍在进行的计时计到迁移时刻),随后清掉该键;损坏的旧记录原样保留。日志首次读取进行中或日志不可用时,遮罩不渲染——可能又被打开的遮罩不如迟到的遮罩。

文案双语:插件在 `dsh-client-locale` 的 `coding-timer` 命名空间注册 zh/en 词典,切换语言会重渲染已挂载的行与日历。

## Model Experience

无。该追踪器是纯浏览器端的健康面板:不挂载工具、不贡献提示词段落、不记录会话事件,其持有的任何内容都不会进入模型请求。

#### KV Cache 影响

无;该包既不组装也不发送提供方请求,零模型 token 开销源于它没有模型可见面。

## 已知限制与延后工作

- **活动文档无界增长**——区间只增不剪(规范 JSON 下每条约 40 字节,一次工作突发一条,数年使用也在存储预算内)。
- **“在场”是输入,不是注意力**——读代码或思考而不碰设备满 `idleMinutes` 分钟会触发遮罩;不合适就在统计弹窗里调大该值。被打断的突发至多损失末尾两枚打点之间的两分钟。
- **偏好仅限回环**——设置 RPC 仅回环可达,远程(局域网)浏览器的 scope 运行在内存模式:遮罩按出厂默认表现,写入入口隐藏而不是吞掉一次无效写入。活动日志本身刻意不做仅回环限制,所以手机与桌面读写的是同一份历史。
- **离线打点排队**——写失败的批次保持待发并自动重试;长时间离线的页签在链路恢复时补齐,但一直连不上的浏览器会在关闭时丢掉该批次。
